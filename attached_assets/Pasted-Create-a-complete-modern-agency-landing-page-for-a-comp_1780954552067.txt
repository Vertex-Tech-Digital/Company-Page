* Next.js
* TypeScript
* Tailwind CSS
* Responsive design
* Clean component structure

Visual style:

* Tech Premium
* Dark mode by default
* Minimalist and modern European corporate aesthetic
* Background: very dark navy/black, not pure black
* Text: white, light gray, muted gray
* Accent color: electric blue
* Use subtle gradients, glassmorphism cards, soft borders, and elegant hover effects
* Add subtle animated elements like glowing gradients, floating code blocks, smooth section reveals, and button hover transitions
